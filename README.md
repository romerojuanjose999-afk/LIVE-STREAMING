# LIVE-STREAMING · Moderación de chat en vivo con Apache Spark

Proyecto de Data Engineering (UNIMINUTO Ibagué): simulación del chat de un directo
que se modera en tiempo real eliminando groserías y spam.

| Carpeta | Versión | Tecnologías |
|---|---|---|
| [`version-1`](version-1) | Productor-consumidor con archivos | Python, Spark Structured Streaming |
| [`version-2`](version-2) | 2 productores + 1 consumidor, guardado por lotes en SQL | Kafka, Spark, MySQL (clases), Docker |

Cada carpeta tiene su propio README con las instrucciones para ejecutarla.
